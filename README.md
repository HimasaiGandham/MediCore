# 📈 MediCore — Interactive Evaluation Dashboard
> **Branch:** `feature/evaluation-dashboard`  
> **Role in MediCore:** A live visual dashboard in the web app to run and inspect benchmarks.

---

### 🌟 What is this branch all about?
While `feature/evaluation` runs tests in the background or terminal, this branch brings those benchmarks to life inside the web interface 📊! It adds the **Grounding Benchmark Suite Tab** directly into the Streamlit app.

---

### 💡 Why do we need this in MediCore?
A professor, judge, or doctor reviewing MediCore shouldn't need to run Python commands in a terminal to see if the system is accurate. They can just click a button on the website and watch the accuracy scores appear in real time! 🖥️✨

---

### ⚙️ How does it work in simple words?
1. **Benchmark Tab:** Adds a dedicated 4th tab to the MediCore web interface 📑.
2. **Test Selector:** Lets users pick from pre-configured clinical queries (cardiology, endocrinology, emergency, unsupported) 🎯.
3. **Live Metrics Display:** Shows real-time metric cards for Top-1 Accuracy, Top-3 Recall, Keyword Coverage, and Grounding Status 📈.
4. **Side-by-Side Comparison:** Displays retrieved evidence side-by-side with the expected answer for easy comparison 🔍.

---

### 🤝 How this branch contributes to MediCore
- 👁️ **Visual Demonstration:** Makes system accuracy immediately visible to any visitor.
- 🧪 **Interactive Testing:** Anyone can test individual queries or the entire test suite with one click.
- 🎓 **Ideal for Presentations:** Perfect for live demos, academic reviews, and project presentations.

---

### 🦄 What makes this branch unique?
This branch bridges **formal evaluation metrics and user interface design**, making complex AI benchmarking simple, visual, and interactive.

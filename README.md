# 🏷️ MediCore — Visual Evidence Cards & Source Display
> **Branch:** `feature/source-display`  
> **Role in MediCore:** Showing colorful, transparent evidence cards with agency badges in the UI.

---

### 🌟 What is this branch all about?
When MediCore finds medical proof, it doesn't just hide it in code! This branch builds **Visual Evidence Cards** 🏷️🎨 in the web interface — complete with organization logos, confidence percentages, and expandable reading boxes.

---

### 💡 Why do we need this in MediCore?
Users want to see where an answer came from at a single glance:
- A blue badge for **NHS** 🇬🇧
- A navy badge for **CDC** 🇺🇸
- A green badge for **WHO** 🌍
- An orange badge for **ICMR** 🇮🇳

Seeing official agency badges and exact similarity scores builds confidence and trust!

---

### ⚙️ How does it work in simple words?
1. **Render Cards:** Formats each retrieved chunk into an attractive card with official badges 🎴.
2. **Similarity Badges:** Displays confidence match percentages (e.g., "78% Match Score") 📊.
3. **Expandable Text:** Users can click to expand the full original excerpt from the official document 📖.

---

### 🤝 How this branch contributes to MediCore
- 👁️ **Visual Clarity:** Makes complex data sources easy to browse and understand.
- 🔍 **One-Click Verification:** Anyone can inspect the exact raw sentence that backed the AI answer.
- 🎨 **Clean Healthcare Aesthetic:** Gives MediCore a polished, professional medical feel.

---

### 🦄 What makes this branch unique?
This branch specializes in **source presentation and transparency UI components**, turning raw database records into clear visual evidence cards.
